# CA LFLT RouteOpt 조건

## 차량 · DC

1. 트럭은 2대만 사용
2. 출발 DC
   - LGC8: 5267 Sierra Ave, Fontana, CA 92336
   - LGC2: 5550 Mango Ave, Rialto, CA 92377
   - LGC7: 5550 Mango Ave, Rialto, CA 92377
3. LGC2와 LGC7은 주소는 같지만 서로 다른 DC: 한 로드는 한 DC에서만 픽업 (투턴으로 LGC2↔LGC7 바꿀 때 이동시간은 0)
4. 트럭 용량: 800 cuft 미만
5. 팔레트가 필요한 건 (HA 제외 전부: AC, ES, BS, MS, …): 400 cuft 미만
6. 팔레트 불필요 건 (HA): 800 cuft 미만
7. 팔레트 필요 건과 불필요 건이 섞여서 같이 출하되는 경우도 위 기준 적용

## 시간

8. 최대 근무 10시간, 로딩 포함·DC 복귀까지 (예: 06:00 시작 → 16:00 복귀, 08:00 시작 → 18:00 복귀)
9. 기사 시작 시각 = 첫 배송 시각(08:00) − 아침 로딩 1시간 30분 − DC→첫 스톱 이동시간. 단 창고가 06:00에 열리므로 06:00보다 일찍 시작할 수 없음. 첫 스톱이 멀면 06:00 시작 → 07:30 출발 → 이동시간 후 도착 (08:00 이후)
10. 첫 배송은 08:00부터
11. 스탑 간 이동 추가시간(Stops in transit): 스탑→스탑 이동마다 20분 (Advanced settings에서 변경)
12. 하차(서비스) 시간: 쉽먼트 cuft × 0.1분, 스탑별 합계
13. 점심 30분, 11:00~14:00 사이

## 거리

14. 편도 200mi 미만
15. 150~200mi 구간은 협력사(Carrier)와 사전 확인 필요
16. 스탑 수 제한 없음

## Two Stop Rule

17. 총 거리는 편도 200mi 미만
18. 스탑 간에는 이동시간 + 하차시간을 반드시 확보
19. 스탑 간 거리가 50mi 미만이면 총 2시간 확보 (이동 1시간 + 하차 1시간)

## Two Turn Rule

20. 투턴 기능 필요
21. 투턴 시 전체 왕복 거리 300mi 미만
22. 회차 사이 최소 3시간 확보 (Live Loading이라 복귀와 상차 시간 고려)
23. 2회차 출발 시각 = 늦은 쪽 (① 복귀 + DC 간 이동 + 오후 로딩 2시간, ② 1회차 마지막 배송 + 3시간)
24. 점심은 회차 사이에

## 배정 우선순위

25. Priority 1 = 기존 LFLT, 2 = 추가 후보, 3 = 낮음
26. DC에서 가까운 주문 먼저
27. GRND를 포함해서 최적화하는 버전과 빼고 최적화하는 버전을 둘 다 돌릴 수 있으면 좋겠음
28. GRND를 포함해서 최적화하는 경우 GRND는 맨 후순위
28a. 우선순위 2 스탑은 스탑 수와 볼륨을 같이 봄: 스탑 1개 = 1 + cuft / 100 (Advanced settings "Volume value"). 트럭이 모자랄 때 스탑 수와 장입량을 같이 높임. 우선순위 1(기존 LFLT 로드)은 항상 먼저.
    1. GRND를 뺀 나머지로 먼저 최적화
    2. 그다음 남는 시간과 용량에만 GRND를 끼워 넣음
    3. GRND는 이미 배정된 스탑에서 5mi 이내일 때만 추가
    4. GRND를 넣으려고 이미 배정된 스탑을 빼지 않음
    5. GRND를 넣은 뒤에도 1~24번 조건은 모두 지킴
